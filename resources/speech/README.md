# LotaGate speech runtime

The `runtime/` and `manifest.json` entries are generated by
`npm run speech:prepare`. They are intentionally excluded from source control
because the native whisper.cpp executable is a release asset. The model is
not generated into this directory: the Desktop main process downloads it on
first use into the per-user cache.

The preparation script pins the whisper.cpp release and model URL, records the
model SHA-256 and expected size in `manifest.json`, verifies supported runtime
archives with SHA-256 where an upstream digest is available, and copies only
the CLI executable and its native libraries into the resource tree consumed by
Electron Forge. Model download is bounded, streamed, checksum-validated, and
committed to the cache with an atomic rename.
