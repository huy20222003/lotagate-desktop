# Computer Use

Computer Use lets LotaGate operate an approved Windows application through its native host capability. The plugin contains agent guidance only; Desktop owns window targeting, UI Automation patterns, input dispatch, screenshots, OCR, permissions, approval, and cancellation.

The plugin exposes window discovery, inspection, screenshots, OCR, text/value access, semantic control actions, pointer and keyboard input, window state management, application launch, waiting, and normal window close operations. Semantic actions are used when the inspected control reports the required Windows UI Automation pattern; coordinate input remains available for controls that do not expose a suitable pattern.
The public surface also supports reading selections and bounded grids, selecting
text occurrences, inspecting connected displays, reading and writing the text
clipboard, waiting for a control state, and managing standard file dialogs.
